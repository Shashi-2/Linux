<h2> What is GNUGPL</h2>

<ul>
<li>Created by Richard Stallman for the General Public License Project , the GNU ensures software remains free for all user.</li>
<li>Users can run,study,share and modify GPL licensed software.</li>
<li>Key rule - modification also be shared known as "Copyleft".</li>
<li>GPL promotes shared ownership and collaboration in the Software Market.</li>
</ul>



<h2>Introduction to Linux</h2>

<ul>
<li>First free Unix like Operating System and introduced by Linus Torvalds in 1991.</li>
<li>The combination of GNU utility and linux Kernel is the complete OS.</li>
<li>The Free Software Foundation promotes the development and use of Free software (Mainly GNU OS or GNU/Linux)</li>
</ul>
<h3>-->Free Software Foundation</h3>
      Promotes the user rights to use ,study, copy, modify and use free software ....4 freedoms=>
<ol>
<li>To run the program,for any purpose.</li>
<li>To study how the program works, and adopt it to your needs.Access to the source code is a precondition for this.</li>
<li>To redistribute copies so you can help your neighbour.</li>
<li>To improve the program and release your improvement and modified version to the public</li>
</ol>
